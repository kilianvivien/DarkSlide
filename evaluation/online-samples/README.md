# Online film-format evaluation sample

`126-film.jpg` is a 1280-pixel Wikimedia Commons derivative of
[`Sample 126 Film.jpg`](https://commons.wikimedia.org/wiki/File:Sample_126_Film.jpg)
by Bigbear213, licensed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

`126-square-frame.tiff` is a test crop made from that image. It retains the
film border, separator, and perforation around one approximately square 126
frame. It is used only by the auto-crop evaluation suite.
