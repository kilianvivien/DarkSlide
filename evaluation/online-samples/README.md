These files are **not** covered by DarkSlide's MIT license.

`126-square-frame.tiff` is a test crop derived from
[`Sample 126 Film.jpg`](https://commons.wikimedia.org/wiki/File:Sample_126_Film.jpg)
by Bigbear213, licensed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). It retains the
film border, separator, and perforation around one approximately square 126
frame, and is distributed under the same CC BY-SA 4.0 license. The crop was
prepared by tdurieux for the auto-crop evaluation suite
(`evaluation/online-formats.test.ts`), which is its only use.
